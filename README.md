# sound-field
声场 / SOUND FIELD

一个运行在浏览器里的声场监测工具。使用 Web Audio API 采集麦克风信号，实时显示声级、峰值保持和音量趋势。所有音频处理均在本地完成，不上传任何音频数据。

功能

· 实时声级显示（未校准时为相对电平 dBFS(A)）
· A 计权
· 峰值保持
· 音量趋势记录
· 参考声级校准（单点偏移修正）
· 纯前端、无后端、无追踪

使用

1. 打开页面，允许浏览器访问麦克风。
2. 页面开始显示实时声级与趋势。
3. 如需接近真实声级的读数，使用参考声级校准。

未校准时页面只显示相对电平，不是计量认证声级计。校准只修正麦克风灵敏度的单点偏移，无法修正消费级麦克风的频响不平坦问题，校准后读数仍为近似值。

技术栈

· 原生 HTML / CSS / JavaScript
· Web Audio API（AnalyserNode）
· 无构建步骤，无框架运行时
· 部署于 Cloudflare Pages

本地运行

直接用浏览器打开 index.html 即可。若浏览器限制麦克风权限，可用任意静态服务器：

bash
python3 -m http.server 8000

然后访问 http://localhost:8000。

隐私

音频仅在浏览器本地处理，不会上传到任何服务器。项目不包含后端、不包含分析脚本、不收集用户数据。
